# 2023 年电赛 H 题：信号分离装置

基于 STM32F407ZGT6 与 AD9833 的信号分离装置学习、开发与测试资料。

## 目录

- `赛题和计划/`：原始赛题与进度清单。
- `数据手册/`：器件手册、开发板原理图及模块说明。
- `其他资料/`：工程创建、模块使用等笔记。
- `firmware/LED_test/`：当前 LED 实验工程，包含 CubeMX 配置、Keil 工程和依赖源码。
- `demos/`：已有示例工程，保留原始目录。

## 当前进度

按当前计划记录：LED 编译、下载及运行已验证；单片 AD9833 已做部分输出实测。按键、串口、采样及自动分离仍待推进。详细状态以 `赛题和计划/当前计划.txt` 为准。

## 打开工程

1. 使用 STM32CubeMX 打开 `firmware/LED_test/LED_test.ioc` 查看配置。
2. 使用 Keil MDK 打开 `firmware/LED_test/MDK-ARM/LED_test.uvprojx`。
3. 按本机环境配置 STM32F4 器件支持包与 ST-Link，再编译、下载。

工具版本与依赖版本尚待补记；当前仓库整理不代表已重新编译或完成硬件复测。
