# 2023 年电赛 H 题：信号分离装置

基于 STM32F407ZGT6 与 AD9833 的信号分离装置学习、开发与测试资料。

## 目录

- `赛题和计划/`：原始赛题与进度。进度大家自己安排，只做参考。
- `数据手册/`：器件手册、开发板原理图及模块说明。
- `其他资料/`：工程创建、模块使用等笔记，当前的引脚分配。
- `firmware/LED_test/`：当前 LED 实验工程，包含 CubeMX 配置、Keil 工程和依赖源码。这里现在只是一些调试用的代码，最终应该会直接改成信号分离代码。


## 当前进度

完成了工程创建：如何从CubeMX创建工程，完成引脚配置，keil中熟悉一下代码结构，如何build和download，进行串口调试和传输。学习AD9833的使用。下一步验证加法器，把AD9833和单片机连接，并用上位机控制AD9833的输出信号。然后先在电脑上根据题目要求做信号仿真，使用FFT，完成代码框架。另一边接通信号的采样。最后把代码放给单片机，进行调试。大概是这么个思路。

## 打开工程

1. 使用 STM32CubeMX 打开 `firmware/LED_test/LED_test.ioc` 查看配置。
2. 使用 Keil MDK 打开 `firmware/LED_test/MDK-ARM/LED_test.uvprojx`。
3. 按本机环境配置 STM32F4 器件支持包与 ST-Link，再编译、下载。
