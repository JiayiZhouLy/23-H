七、阶段 6：验证独立加法器
目标：确认输入 STM32 前的混合信号确实满足题目定义。
- [ ] 确认加法器使用单电源还是双电源。
- [ ] 落实移动电源供电；需要电源转换时，先单独测试电源。
- [ ] 预留 A、B、C 三个测试点。
- [ ] 只输入 A，验证 C 与 A 的增益及相位。
- [ ] 只输入 B，验证 C 与 B 的增益及相位。
- [ ] 确认输出是 \(A+B\)，而不是 \(-(A+B)\)。
- [ ] 输入同频同相的两路信号，检查叠加幅度。
- [ ] 输入 50 kHz 和 100 kHz 正弦波，观察混合波形。
- [ ] 测试三角波输入，检查波形保持情况。
- [ ] 检查整个输入范围内是否削顶、振荡或增益变化。
- [ ] 记录实际输入幅度，避免信号源负载设置导致幅度判断错误。
验收：加法器独立工作，每路输入到输出的增益接近 +1，满足题目波形要求。
最终与分离装置之间只连接 C 和地。
